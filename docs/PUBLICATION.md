# BHI 2026 publication

**Status:** accepted at BHI 2026.

**Paper title:** An Assessment of Gait Feature Preservation in Sparse Inertial Pose Estimation for Parkinsonian Gait Analysis.

The revised paper evaluates geometric fidelity, severity-stratified gait preservation and downstream clinical utility as complementary dimensions. Its inferential conclusions use participant-cluster-aware analysis and multiple-comparison correction. It distinguishes sensor-stream parity from initialization-information parity: models other than TransPose use protocol-specific GT-derived first-frame states.

The public `results/` tables preserve the earlier core benchmark's reported numerical snapshot and nominal trend values, as documented in `results/README.md`. They are not relabeled as the revised manuscript's final inferential tables. The repository provides the core data adapters, model runners and evaluation code; it does not claim to be an exhaustive release of the September rebuttal analysis artifacts.
